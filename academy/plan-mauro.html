Plan de estudio

Los 8 módulos son una estructura. Si un tema ya lo dominás, avanzamos más rápido; si un proyecto necesita más profundidad, la clase se adapta.

MÓDULO 01 · PENDIENTE

Diagnóstico y mapa de proyectos

Ordenamos lo que ya existe y decidimos dónde tiene sentido empezar.

  • Estado de Tele Remate/canal.
  • Estado del sistema de vending.
  • Archivos, computadoras y herramientas.
  • Riesgos y prioridades.

Resultado: un primer proyecto elegido y un mapa claro de lo que necesita para funcionar.

MÓDULO 02 · PENDIENTE

Dirigir bien a la IA

Pasamos de pedir cosas “a prueba y error” a conducir una tarea con instrucciones, criterios y revisión.

  • Prompts y Markdown.
  • Modelo y nivel de esfuerzo.
  • Restricciones.
  • Correcciones y criterios de calidad.

Resultado: una tarea real resuelta y documentada de forma repetible.

MÓDULO 03 · PENDIENTE

Contexto reutilizable

Aprovechamos tus carpetas actuales para que cada proyecto tenga una memoria limpia y actualizable.

  • Zebra.
  • Tele Remate.
  • Vending.
  • Información fija vs. temporal.

Resultado: abrir una sesión nueva sin volver a explicar todo el proyecto.

MÓDULO 04 · PENDIENTE

Investigar y elegir herramientas

Aprendemos a verificar documentación y decidir cuándo Claude alcanza y cuándo conviene usar otra herramienta o conector.

  • Fuentes.
  • Documentación técnica.
  • APIs y conectores.
  • Comparación de alternativas.

Resultado: decisiones técnicas respaldadas y no basadas solamente en una respuesta plausible.

MÓDULO 05 · PENDIENTE

Crear Skills propias

Guardamos procedimientos que ya funcionan para no reconstruir instrucciones y correcciones cada vez.

  • Cuándo crear una Skill.
  • Cómo probarla.
  • Cómo corregirla.
  • Cómo reutilizarla.

Resultado: una Skill real funcionando sobre uno de tus procesos.

MÓDULO 06 · PENDIENTE

Delegar procesos

Conectamos tareas, decisiones y validaciones para que parte del trabajo pueda ejecutarse sin que tengas que iniciarlo manualmente.

  • Workflows.
  • Loops.
  • Tareas programadas.
  • Agentes.
  • Control humano.

Resultado: un proceso completo diseñado para ejecutarse de forma segura.

MÓDULO 07 · PENDIENTE

Construir un piloto funcional

Tomamos el proyecto de mayor prioridad y lo llevamos a una primera versión real.

  • Local vs. nube.
  • GitHub/Vercel si aplica.
  • Base de datos.
  • Integraciones.
  • Seguridad y pruebas.

Resultado: una versión que se puede instalar o probar en el entorno real de Durazno.

MÓDULO 08 · PENDIENTE

Integración y operación

Cerramos el recorrido dejando el sistema medible y mantenible.

  • Monitoreo.
  • Errores.
  • Documentación.
  • Métricas.
  • Roadmap del siguiente proyecto.

Resultado: poder operar y seguir desarrollando lo construido por tu cuenta.

Cómo vamos a trabajar: cada clase empieza revisando lo anterior. Si está estable, avanzamos. Si algo no funcionó, primero lo corregimos y lo dejamos probado. La meta no es “ver ocho temas”; es terminar con capacidades que puedas usar fuera de la clase.
