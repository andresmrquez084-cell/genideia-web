¿Cuándo tiene sentido pensar en un workflow?

Tiene sentido hablar de workflow cuando:

01Una tarea tiene varias etapas conectadas.
02El resultado de un paso alimenta al siguiente.
03Existen decisiones entre etapas.
04Hay acciones que dependen de resultados anteriores.
05Queremos visualizar el proceso completo.
06Queremos repetir ese proceso de forma consistente.
07Queremos detectar qué partes podrían automatizarse.
08Queremos identificar si dentro del proceso existen loops.

Prompt del loop

02_loop_revision_plan.md
Revisá el plan anterior según estos criterios: 1. Máximo tres prioridades principales. 2. Cada prioridad debe tener una acción concreta para esta semana. 3. El plan tiene que respetar mi disponibilidad real. 4. No debe incluir información que yo no haya proporcionado. Para cada criterio indicá: - Cumple - No cumple - Qué debe corregirse
Si algún criterio no se cumple: 1. corregilo; 2. volvé a evaluar; 3. repetí el proceso. Detenete cuando: - todos los criterios se cumplan, o - hayas realizado un máximo de 3 iteraciones. Al finalizar, mostrame únicamente la versión final y un resumen de qué cambió.
