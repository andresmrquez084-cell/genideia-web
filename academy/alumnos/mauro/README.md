# Mauro Mondino — Plan personalizado

## Estado

**Planificado**

Inicio previsto después de su regreso a Uruguay.

## Perfil actual

Mauro ya usa Claude Desktop de forma autodidacta.

Tiene carpetas separadas por proyectos y ha experimentado con:

- edición de videos;
- generación de materiales;
- desarrollo de un sistema propio;
- organización de archivos por proyecto.

No parte de cero. El objetivo es convertir ese uso exploratorio en una forma de trabajo estable y repetible.

## Proyectos prioritarios

### Tele Remate / canal de televisión

La familia opera Tele Remate y un canal local.

Existe una tarea repetitiva: preparar la programación diaria del canal.

La oportunidad es construir un proceso que:

- lea los programas disponibles;
- compruebe actualizaciones en carpetas;
- arme o prepare la programación;
- detecte faltantes;
- reduzca trabajo manual;
- mantenga control humano antes de emitir.

### Máquinas expendedoras

Mauro importó con su hermano tres máquinas expendedoras.

Ya empezó a explorar un sistema propio.

Quiere poder visualizar o recibir información sobre:

- ventas;
- producto vendido;
- stock restante;
- método de pago;
- máquina;
- notificaciones por WhatsApp o Telegram.

El proyecto debe probarse en una máquina antes de escalar.

### Contenido

También usa IA para editar videos y materiales para:

- Zebra;
- proyectos propios;
- un centro de estética facial.

Este caso puede servir para enseñar Skills y procedimientos reutilizables.

## Objetivo general

Que Mauro pueda:

1. dirigir mejor a Claude;
2. organizar contexto por proyecto;
3. investigar decisiones técnicas;
4. convertir tareas repetidas en Skills;
5. construir procesos de varios pasos;
6. programar o delegar tareas;
7. desplegar un piloto real;
8. mantener y ampliar lo construido por su cuenta.

## Metodología

**PROYECTO REAL → CONSTRUIR → PROBAR → ENTENDER → ESTABILIZAR → DOCUMENTAR → REUTILIZAR**

Las clases no se organizan alrededor de funciones aisladas.

Cada concepto se conecta con un proyecto que Mauro ya quiere ejecutar.

## Criterio de avance

No se avanza porque el tema fue explicado.

Se avanza cuando Mauro puede:

- ejecutarlo;
- explicar qué está ocurriendo;
- detectar qué información falta;
- corregir un error;
- volver a usar el procedimiento.
