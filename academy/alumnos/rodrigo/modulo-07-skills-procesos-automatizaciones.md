# Módulo 07 — Skills, procesos y automatizaciones

## Objetivo
Empaquetar solamente tareas ya validadas y conectarlas cuando tenga sentido.

## Principio
No automatizar un proceso que todavía cambia o no produce un resultado confiable.

## Recurso 1 — Detector de candidato a Skill

Tarea:
[DESCRIBIR]

Evaluá:
- ¿se repite?
- ¿el objetivo es estable?
- ¿las entradas son conocidas?
- ¿los pasos son repetibles?
- ¿las reglas están claras?
- ¿el resultado puede auditarse?

Resultado:
SKILL AHORA / DOCUMENTAR PRIMERO / NO NECESITA SKILL

## Recurso 2 — Constructor de Skill

Creá una Skill para esta tarea validada:
[PROCESO]

Debe definir:
- qué hace;
- qué información necesita;
- pasos;
- fuentes permitidas;
- decisiones;
- reglas;
- validación;
- resultado;
- cuándo detenerse y pedir ayuda humana.

No agregues contexto de otros procesos.

## Recurso 3 — Mapa de proceso

Representá:
DISPARADOR → PASOS → DECISIONES → HERRAMIENTAS → RESULTADO → REGISTRO

Para cada decisión indicá:
- condición;
- sí;
- no;
- falta información;
- requiere humano.

## Recurso 4 — Detector de automatización

Analizá este proceso:
[PEGAR]

Clasificá cada paso:
- MANUAL HUMANO
- IA ASISTE
- AUTOMATIZABLE
- REQUIERE VALIDACIÓN
- NO AUTOMATIZAR

Justificá por riesgo y valor.

## Recurso 5 — Auditor de automatización

Antes de activar:
- fuente correcta;
- permisos mínimos;
- registro;
- errores;
- fallback;
- revisión humana;
- prueba con casos;
- datos sensibles;
- acción reversible.

## Criterio de avance
Rodrigo puede explicar qué hace la automatización, qué información usa y dónde interviene él.
