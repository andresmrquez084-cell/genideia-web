# Módulo 04 — Investigación técnica y búsqueda de repuestos

## Objetivo
Reducir tiempo de búsqueda entre múltiples catálogos y fuentes manteniendo trazabilidad.

## Resultado
Un flujo de búsqueda repetible para aplicaciones, equivalencias, medidas y códigos.

## Recurso 1 — Mapa de fuentes por categoría

Categoría: [RULEMANES / CRUCETAS / PASTILLAS / ETC.]

Construí una matriz:
| Fuente | Tipo | Qué dato aporta | Autoridad | Actualización | Limitación |

Ordená las fuentes por prioridad de consulta.

## Recurso 2 — Comparador de equivalencias

Compará:
Código A: [...]
Código B: [...]

Buscá/analizá:
- fabricante;
- medidas;
- aplicación;
- posición;
- variantes;
- código OEM;
- referencias cruzadas.

No declares equivalencia solo porque comparten una medida.

Resultado:
EQUIVALENTES / POSIBLE EQUIVALENCIA / NO EQUIVALENTES / INFORMACIÓN INSUFICIENTE

Justificá con fuentes.

## Recurso 3 — Constructor de flujo de búsqueda

Documentá el proceso que seguimos para resolver esta consulta:
[CASO]

Convertí lo realizado en:
1. datos mínimos;
2. orden de fuentes;
3. decisiones;
4. condiciones de descarte;
5. validación final;
6. formato de respuesta.

Marcá qué pasos fueron manuales y cuáles puede ejecutar IA.

## Recurso 4 — Benchmark

Registrar 10 consultas:
| Caso | Tiempo manual estimado | Tiempo con IA | Fuentes consultadas | Resultado correcto | Correcciones | Aprendizaje |

## Criterio de avance
El sistema reduce tiempo de búsqueda y no empeora la precisión. Si la precisión no está validada, no se automatiza la respuesta al cliente.
