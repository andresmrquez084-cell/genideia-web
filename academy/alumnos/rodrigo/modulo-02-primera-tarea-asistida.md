# Módulo 02 — Resolver una tarea real con IA

## Objetivo
Resolver una tarea completa con IA, revisarla y entender qué información necesita para ser confiable.

## Caso sugerido
Consulta técnica de repuesto o equivalencia.

## Resultado
Rodrigo debe poder repetir:
NECESIDAD → DATOS → FUENTES → RESPUESTA → REVISIÓN → CORRECCIÓN → REGISTRO

## Recurso 1 — Definidor de tarea

Tengo que resolver esta tarea real:
[DESCRIBIR]

Antes de hacerla:
1. decime qué información necesitás;
2. separá imprescindible de útil;
3. indicá qué información no deberías inventar;
4. proponé el resultado final;
5. definí qué debería revisar yo antes de usarlo.

No ejecutes todavía si faltan datos críticos.

## Recurso 2 — Investigador de repuesto

Necesito identificar o comparar un repuesto.

Datos disponibles:
- vehículo:
- año:
- versión/motor:
- posición/eje:
- código:
- medidas:
- foto:
- marca:
- otra información:

Reglas:
1. no asumir aplicaciones;
2. usar primero fuentes proporcionadas;
3. si necesitás web, priorizar fabricante/catálogo/proveedor confiable;
4. separar DATO de INTERPRETACIÓN;
5. mostrar código, aplicación, medidas y fuente;
6. señalar contradicciones;
7. usar estados:
   - CONFIRMADO
   - PROBABLE
   - FALTA INFORMACIÓN
   - CONTRADICTORIO
   - NO ENCONTRADO

Entregá candidatos y qué falta validar antes de cotizar.

## Recurso 3 — Auditor técnico

Auditá esta respuesta técnica:
[PEGAR]

Revisá:
- ¿cada aplicación tiene fuente?
- ¿se confundió equivalencia con similitud?
- ¿faltan año/motor/ABS/medida/posición?
- ¿hay contradicciones?
- ¿se afirmó algo que era solo probable?
- ¿qué debería verificar Rodrigo antes de responder?

Resultado:
APROBABLE / NO APROBABLE
+ correcciones exactas.

## Recurso 4 — Registro de aprendizaje

Hoy confirmé este dato:
[PEGAR]

Transformalo en una ficha reutilizable con:
- tipo de conocimiento;
- producto/código;
- equivalencia;
- aplicación;
- medidas;
- fuente;
- fecha;
- quién lo validó;
- nivel de confianza;
- observaciones;
- cuándo debe volver a revisarse.

## Criterio de avance
Una tarea real debe resolverse de punta a punta con menos fricción y con una revisión explícita antes de usar la respuesta.
