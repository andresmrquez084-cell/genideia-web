# Plantilla de prompt simple

Sirve para pedirle casi cualquier cosa a una IA (ChatGPT, Claude) de forma clara. Se usa por primera vez en el Módulo 2.

```
Rol: [quién querés que la IA sea o qué perspectiva debe tomar]
Objetivo: [qué querés lograr con esta respuesta]
Contexto: [datos, situación, antecedentes relevantes]
Restricciones: [qué no debe hacer, límites, cosas a evitar]
Formato de salida: [lista, tabla, texto corrido, cantidad de palabras]
Criterio de calidad: [cómo vas a saber que la respuesta sirve]
```

## Ejemplo aplicado (plan personal)

```
Rol: actuá como un coach de productividad práctico, sin frases motivacionales vacías.
Objetivo: ayudarme a construir un plan realista para los próximos 90 días.
Contexto: trabajo como setter en las mañanas, tengo un proyecto de autos con un socio
por las tardes, y quiero ordenar rutinas, hábitos y energía mental. Disponibilidad
real: 1-2 horas libres por día entre semana.
Restricciones: no me des una lista genérica de 20 hábitos. Priorizá máximo 3 focos.
Formato de salida: tabla con columnas Mes / Foco principal / 2-3 acciones concretas.
Criterio de calidad: que cada acción sea algo que pueda hacer esta semana, no una idea abstracta.
```

## Cómo revisar si el prompt está bien armado

- ¿Tiene los 6 elementos o al menos los que importan para el caso?
- ¿Un desconocido podría entender la tarea sin preguntar nada más?
- ¿Definiste cómo se ve una buena respuesta?
