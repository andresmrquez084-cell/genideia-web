# Plantilla de kit comercial para un auto

Se usa en el Módulo 5.

```
Descripción larga: [para la publicación completa]
Descripción corta: [para redes o resúmenes]
Copy de anuncio: [para pauta paga]
Guion de video: [tomas + texto en pantalla, 20-30 segundos]
Checklist de tomas: [qué fotos/videos necesita el editor]
Brief para editor: [instrucciones claras de armado]
Preguntas frecuentes del comprador: [3-5 preguntas típicas + respuesta]
```

## Cómo generarlo con IA

Partir de los datos del auto (los mismos de la tabla de comparación) + el precio ya
definido. Pedir cada pieza por separado la primera vez, después probar pedir el kit
completo de una sola vez y comparar calidad.
